# Котодвор

Мод для Claude Code: маленький уютный двор с котами в боковой панели терминала.
Насыпаешь корм — коты приходят сами, едят, сидят и моргают, спят, бродят по двору,
играют друг с другом и уходят. Миски хватает примерно на четыре часа. Время идёт и
пока Claude Code закрыт: открываешь панель — и видишь двор таким, какой он сейчас.

Пять котов (трёхцветная, рыжий, серый, чёрный, белый) нарисованы пиксель-артом
в японском «каваий»-стиле. Никаких донатов, валюты и уведомлений.

## Установка

В терминальной сессии Claude Code:

```
/plugin install kotodvor --marketplace nottolstybai/nekomodtsume
```

Ответь `y` на вопрос о добавлении маркетплейса, затем выбери область установки (Enter — для пользователя).

Из обычной оболочки:

```
claude plugin install kotodvor --marketplace nottolstybai/nekomodtsume
```

## Как играть

- Панель «Котодвор» открывается сама, если окно терминала достаточно широкое; иначе набери `/kotodvor`.
- Кнопка «Насыпать корм» под двором наполняет миску. Первый кот приходит через минуту-две.
- Работает в терминале (нужен truecolor: Ghostty, Windows Terminal, iTerm2, kitty и т. п.).
- Анимация идёт около трёх кадров в секунду и только пока панель видна.

## Разработка

`claude plugin validate .` и `claude plugin test .` в папке репозитория.
